# Logos institucionales

Coloca aquí los tres logos, en PNG con fondo transparente, con exactamente estos nombres:

| Archivo        | Institución                                                             |
| -------------- | ----------------------------------------------------------------------- |
| `unach.png`    | Universidad Autónoma de Chiapas                                           |
| `cecocise.png` | Centro de Estudios para la Construcción de la Ciudadanía y la Seguridad   |
| `mddh.png`     | Maestría en Defensa de los Derechos Humanos                               |

## Mientras no existan los archivos

La portada y el cierre muestran un **espacio reservado** con borde punteado y el nombre de
cada logo, del mismo tamaño que ocupará la imagen. En cuanto subas los PNG, el espacio
reservado se sustituye automáticamente por el logo.

## Requisitos del archivo

- PNG con canal alfa y fondo completamente transparente.
- Sin marcos, sombras ni márgenes incorporados.
- Proporción original, sin deformar ni recortar.
- Resolución recomendada: 600 px o más en el lado mayor.

## Color y comportamiento

El archivo no se modifica: el tono se adapta al tema con filtros CSS
(`src/index.css`, clase `.institutional-logo`). Los logos son estáticos: no rotan,
no se escalan ni se desplazan.
